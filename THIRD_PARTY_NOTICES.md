# Third-Party Notices

iretable-tools is released under the MIT License (see [LICENSE](LICENSE)).

The released `iretable.exe` has **no third-party runtime dependencies**. It is
standard C++20 and the C runtime, linked statically. The Cheat Engine `.CT`
reader is a small hand-written XML parser in `src/iretable/Xml.cpp`, so no XML
library is bundled or downloaded for the tool itself.

One component is used by the tests only and is neither linked into the CLI nor
shipped in the release zip.

## Catch2 3.5.2 (Boost Software License 1.0), tests only

- Upstream: https://github.com/catchorg/Catch2
- Pinned at tag `v3.5.2`, fetched at configure time by the test build.
- Used by the unit tests. It is not part of `iretable.exe` and does not ship in
  the release zip.
